# No Distract by Wasted

A Chrome (Manifest V3) extension with one panel to switch distraction-removal features on or off.

- Hide the YouTube "Up next" sidebar and left navigation menu
- Focus home feed ("No Distraction is ON" screen)
- Block Shorts
- Ad, tracker and popup-ad blocking
- Dark Reader mode and Black & White mode
- Master power button

All features are off by default.

## Install
1. Download or clone this repo.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select this folder.
